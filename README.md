# Dekoruma: Kualitas Pengiriman dan Instalasi

Analisis Failed Installation dan jeda kirim–rakit dari data order Dekoruma (Jan–Des 2023).

## Temuan utama
- Failed Installation 14,07% (Missing Parts 9,08%, Damaged Panel 4,99%).
- Missing Parts terkonsentrasi di dua supplier (±31% vs ±6% supplier lain).
- Rakit di hari pengiriman baru 13,2%; rata-rata jeda 2,55 hari.

## Isi repo
- notebook/: analisis lengkap (Python, pandas, SciPy, Matplotlib)
- report/: laporan presentasi (PDF)
- dashboard/: tangkapan layar dan tabel agregat dashboard
